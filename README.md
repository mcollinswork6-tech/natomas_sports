# Natomas Sports Association Website

Official website for **Natomas Sports Association**, featuring our flagship **Travel Baseball** program and future **Multi-Sport Development** (Basketball, Soccer, Speed & Agility clinics) in Natomas, Sacramento, CA.

- **Domain:** `natomassportassocition.org`
- **Tech Stack:** HTML5, Tailwind CSS, Vanilla JS, Custom SVG Vector Branding. Zero external build tooling required.

## Quick Start
Open [index.html](index.html) directly in any browser, or run:
```bash
python3 -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080).

See [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md) for step-by-step instructions on deploying to free static hosting (Cloudflare Pages, Netlify, or GitHub Pages) and linking your GoDaddy domain.
